## گزینه‌های زبان (هنوز باز)

| گزینه | مزیت | عیب |
|---|---|---|
| Go + [gotk4](https://github.com/diamondburned/gotk4) | هم‌زبانی با بک‌اند، toolchain واحد | کتابخانه community است |
| Python + PyGObject | سریع‌ترین توسعه، مستندات فراوان | نیاز به پایتون روی سیستم هدف |
| Rust + gtk4-rs | official-ish binding | زنجیره build سنگین‌تر |
